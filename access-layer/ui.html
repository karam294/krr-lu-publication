Ask LU's publications

A question in English about Lebanese University's papers, 2022 to 2025, as OpenAlex records them. Gemini writes a SPARQL query; the layer checks it, repairs it if needed, runs it on the graph, and shows the answer with the query that computed it. When the graph holds no such fact, it says so.

Each question is sent to Google's Gemini with the graph's description and a few example queries, never the data itself; on the free tier Google may use what it receives. The answer comes from the graph (graph/openalex), through the query shown under it.
